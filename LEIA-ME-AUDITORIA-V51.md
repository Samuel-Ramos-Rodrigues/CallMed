# CallMed V51 — Estilização auditada

Este ZIP é **o projeto completo**: inclui solution `.sln`, controllers, services, views, JS, CSS, banco/migrations, mobile Android em Kotlin e APK Release 50.0.0. **Não é um kit de CSS isolado.**

Para a auditoria detalhada: `docs/ui/AUDITORIA-INTEGRAL-DE-ESTILOS-V51.md`. A biblioteca visual de referência é sintética e está em `docs/ui/PREVIAS-SINTETICAS-V51`.

Mudanças concentradas em três arquivos CSS, no cache PWA e nos contratos dos testes da interface; APIs, banco e aplicativo Android não foram alterados.

Ainda é necessário compilar a solução .NET e testar no Render/homologação após implantar. Se o site parecer miniaturizado, pressione **Ctrl+0** no navegador: isso redefine o zoom independentemente do CSS.

A **chave de assinatura `.jks`**, as senhas e `keystore.properties` NÃO são distribuídos.
